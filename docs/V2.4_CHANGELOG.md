# RescueNepal.info v2.4 — Practical Field Workflow

v2.4 simplifies v2.3 for rapid use during floods, landslides and mass-rescue operations while preserving restricted DVI/security controls.

## Missing Person
- Replaces the ambiguous Purpose of Going field with **Person Category**: Local, Worker, Tourist, Student, Other.
- Adds **Work Institution / Office / Destination / School Name**.
- Legacy purpose columns remain internally for backward compatibility/import/export.

## Rescued Person
Condition-first workflow with four field states:
- Safe / सकुशल
- Injured / घाइते
- Semi-conscious / अर्धचेत
- Unconscious / अचेत

Safe persons use a short identity/contact workflow. Injured/semi-conscious/unconscious persons use approximate age, gender, document clues, appearance and current hospital/shelter details.

Registration captures who rescued/reported the person (Nepal Army, Nepal Police, APF, shelter, hospital, volunteer/rescuer, local government, NGO/INGO or other), rescue location and current responsible institution.

## Dead Body / DVI
- Approximate gender and age
- Found location and river/waterbody
- Recovered by Nepal Army / Nepal Police / APF / Local Volunteers / Other
- Restricted multiple body photographs
- Body condition
- Documents found
- Clothes, birthmarks, tattoos, scars and belongings
- Shifted-to hospital/mortuary/dead-body facility
- Unique **Body Trace ID: RN-DVI-...**
- Advanced DNA/fingerprint/dental/PM fields remain available to authorized staff only.

## Universal Family Search
Public Universal Search is focused on only:
1. Rescued Person — name, mobile, document clues, location and identifying description.
2. Dead Body — Body Trace ID, huliya/appearance, documents found, clothes, marks and found location.

Full document numbers, forensic data and deceased photographs are never publicly displayed.

## Tracing, Reunification and Handover
- Link rescued/deceased records to an existing Missing Case ID.
- Missing Case ID can be selected from suggested matches or entered manually.
- If no missing case exists, link a Family Match Request or record direct family verification.
- Record recipient/family details, responsible officer, verification/procedure notes and witnesses.
- Authorized approvers can close resolved records during handover; operators use closure approval where required.
